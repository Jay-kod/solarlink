# SolarLink System Portals

This document contains direct links to all the key portals and public pages in the SolarLink system for quick access during development (assuming the server is running on `http://localhost:3000`).

## 🔐 Authentication Portals

### Customer Portal
*   **Login:** [http://localhost:3000/user/login](http://localhost:3000/user/login) (or just `/login`)
*   **Register:** [http://localhost:3000/user/register](http://localhost:3000/user/register)

### Technician Portal
*   **Login:** [http://localhost:3000/technician/login](http://localhost:3000/technician/login)
*   **Register:** [http://localhost:3000/technician/register](http://localhost:3000/technician/register)

### Vendor (Supplier) Portal
*   **Login:** [http://localhost:3000/vendor/login](http://localhost:3000/vendor/login)
*   **Register:** [http://localhost:3000/vendor/register](http://localhost:3000/vendor/register)

### Admin Gateway
*   **Login:** [http://localhost:3000/admin/login](http://localhost:3000/admin/login)
*   *(Note: Admins cannot self-register for security reasons. Admin accounts must be created directly in the database or via artisan).*
